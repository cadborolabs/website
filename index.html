03 Get Started

Install in minutes — wherever you use Claude

Pick the surface you already work in. Each skill is a small, open-source bundle that drops right in.

1

Claude apps (web & desktop)

In Claude's settings, open Skills under Capabilities, choose Create skill, and upload the skill folder as a ZIP.

Settings → Skills → Create skill → upload .zip
2

Claude Code

Drop the skill into your skills directory — Claude Code picks it up automatically. Use a per-project folder to share it with your team via git.

~/.claude/skills/product-roadmap-skill/
3

Cadboro marketplace (one command)

Add the Cadboro Labs marketplace once inside Claude Code, then install any skill by name. Updates come automatically.

/plugin marketplace add brandonsgitstub/cadboro-marketplace /plugin install product-roadmap@cadboro-labs

Then just ask:

claude "Turn our backlog into a roadmap — the goal this half is activation"

Custom skills require a Pro, Max, Team, or Enterprise plan with code execution enabled. Skills don't sync across surfaces — install on each one you use.
