03 Get Started

Up and running in three steps

No enterprise sales cycle. No implementation project. Just install and go.

1

Install Claude Code

The CLI that powers the skills. One command to install globally.

npm install -g @anthropic-ai/claude-code
2

Add the skills you need

Pick one skill or install the whole suite. Each works independently.

claude skill install prd-skill
3

Start building

Use natural language. Ask Claude to write a PRD, generate stories, or prioritize your backlog.

claude "Write a PRD for our new onboarding flow"
