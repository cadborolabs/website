03 Getting Started

Three steps to superpowers

Install in Code mode (terminal). Skills work across all your projects.

1

Open Claude Code

Switch your project to Code mode (terminal). Skills install once and work across all your projects.

2

Add the marketplace

Set up the marketplace once, then install any skill from it.

/plugin marketplace add brandonsgitstub/cadboro-marketplace
3

Install any skill

Describe your task — Claude triggers the skill automatically.

/plugin install prd-generator@cadboro-labs

Prefer claude.ai over the terminal? Each skill's repo has a manual-upload option:
Enable Settings → Capabilities → Code Execution & File Creation, download the repo,
and upload the skill folder under Customize → Skills.
